Methodology

数据口径与方法说明

1. 数据链路

后台按计划访问国家、省级和市级科技主管部门、实验室及其他公开来源。核验后的公开数据由 API 生成快照，GitHub Actions 定时拉取快照并发布到 GitHub Pages。

官方公开来源 → Cloudflare 抓取与 D1 数据库 → 公共 JSON 快照 → GitHub Actions → GitHub Pages

2. 收录范围

  • 量子通信、量子计算、量子精密测量及关键材料器件相关课题。
  • 网络安全、数据安全、抗量子密码等与量子安全产业存在直接关联的项目。
  • 正式指南、征求意见、申报通知、项目建议征集，以及可用于研判后续申报机会的公开信息。

3. 阶段定义

  • 正在申报：存在明确申报窗口或截止时间。
  • 待发布：指南征求意见、项目建议征集等已释放后续正式申报信号。
  • 已截止：已超过公开申报截止时间，继续保留用于历史规律和年度预测。

4. 使用边界

页面用于机会发现和辅助研判。申报资格、任务指标、预算、截止时间等关键事项，应以项目主管部门最新正式通知及申报系统为准。来源抓取受官网可访问性影响，异常会在“来源覆盖”中留痕。

# quantum-opportunity-radar
Quantum opportunity radar

## 镜像的数据与状态

GitHub Pages 每日北京时间 18:30 从 Cloudflare 公共 API 生成快照。页面展示课题成功同步时间；快照生成时间仅表示镜像构建时间，不代表采集成功。

- 课题、团队、来源覆盖和元数据分别读取，15 秒超时后显示明确错误，可点击“重新读取数据”。
- 无成功同步时间、超过 48 小时未同步、种子/回退数据均会提示。
- 正在申报的统计、列表和 Excel 导出使用一致的过期判断。只有日期的截止时间按北京时间当天结束计算。
- 筛选与排序保存在网址中，可使用“分享当前筛选”。截止时间排序在申报阶段分组内生效，无截止时间的记录排在该组最后。
- 官方入口目录是静态登记清单，抓取异常以“来源覆盖”的快照为准。

## 验证

使用 Node.js 22.13 或更高版本运行 `npm test`。Pages 发布前自动执行测试。

此仓库不包含 Cloudflare Worker/采集后台源码。修改此仓库仅更新 GitHub Pages 镜像，不会修改 Cloudflare 主站。
